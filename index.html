Featured Interaction

EEG Blink-Controlled Flappy Bird

Brain-Computer Interface / Signal Processing / Machine Learning

A real-time BCI project that translates EEG blink activity into game-control commands.

Pipeline

  1. EEG acquisition using OpenBCI
  2. Bandpass filtering from 1–10 Hz
  3. Blink/rest segmentation
  4. CSP spatial filtering
  5. Log-variance feature extraction
  6. LDA classification
  7. Prediction converted into a Flappy Bird jump command
